# 콘텐츠 추출본 (apro_home -> 신규 웹사이트 이관용)

디자인/레이아웃을 뺀 **텍스트 · 데이터만** 정리한 결과물입니다.
생성 스크립트: `scripts/export-content.ts` (재실행: `npx tsx scripts/export-content.ts`)

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `01_투자정보_재무정보.md` | 재무제표 4종 x 5개년 표 + 화면 문구(KOR/ENG) |
| `02_지속가능경영.md` | ESG 개요 · 환경/안전보건 · 사회 · 거버넌스 · 제보센터 · 게시판 문구 (한국어) |
| `02_지속가능경영_EN.md` | 위 항목 영문본 |
| `03_커뮤니티.md` | 공지사항 · 보도자료 · ESG 게시판 글 목록 |
| `policies/*.md` | 정책 전문 7종 (윤리헌장 · 윤리강령 · 공정거래 · 인권 · 협력사 · 환경방침 · 내부회계관리규정) |
| `posts/**/*.html` | 게시글 본문 원문 HTML (위지윅 산출물, 그대로 이식 가능) |
| `ASSETS.md` | 같이 옮겨야 할 이미지 · PDF 목록 (원본 존재 여부 포함) |
| `data/*.json` | 기계 이식용 원본 구조 (KOR/ENG 동시 포함) |
| `data/*.csv` | 엑셀 확인용 (UTF-8 BOM) |

## 데이터 건수

| 항목 | KOR | ENG |
| --- | ---: | ---: |
| 공지사항 | 6 | 5 |
| 보도자료 | 2 | 2 |
| ESG 게시판 | 5 | 5 |

- 재무제표: 20건 (별도/연결 x 재무상태표/손익계산서 x 2021~2025)
- 첨부파일: 4건 (실물 파일은 `public/` 하위, `data/posts-all.json` 의 fileUrl 참고)

## 먼저 확인할 것

- 본문이 **이미지뿐인 글 10건** (주로 ESG 게시판) — 옮길 텍스트가 없고 이미지가 곧 콘텐츠입니다.
- **테스트/더미로 의심되는 글 5건** — 제목 기준 자동 판정. 상세는 `03_커뮤니티.md` 5장.
- 보도자료(PRESS) 4건은 내용이 에이프로와 무관한 AI 도구 소개글입니다. 실제 보도자료가 아닌지 확인하세요.
- 공정거래 가이드북은 텍스트가 아니라 **PDF 파일**입니다 (`policies/fair-trade.md` 참고).
